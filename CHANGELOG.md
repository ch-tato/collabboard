# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - Initial Release

### Added
- Real-time collaborative canvas with WebSocket synchronization.
- Drawing primitives: pencil, shape, text, and arrow.
- Real-time tracking of user cursor positions.
- Cursor chat feature for quick communication.
- Image upload support (up to 2MB).
- Undo and redo functionality.
- Automatic canvas deletion after 24 hours of inactivity.
- Backend architecture using Python, Redis, PostgreSQL, and Nginx.
- Frontend implemented with HTML5 Canvas and vanilla JS.
